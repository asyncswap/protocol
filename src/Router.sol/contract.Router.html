Inherits: EIP712

Title: Router

Author: @msakiart

Thin entrypoint for makers (swap), fillers (fillOrder), and makers cancelling orders (cancelOrder). All three actions go through IPoolManager.unlock so the hook can operate on PM debts. Gasless variants (swapWithSig, cancelWithSig) take the maker's EIP-712 signature so a relayer can submit. Signed creates pull input through Permit2 with the order as witness, so the wallet shows the full order (tokens, amounts, pool) in one readable message.

swap

Maker submits a new async order. userData must encode AsyncSwap.UserParams with executor == address(this) so the router is authorized to fill later. userData.amountOutMin MUST equal order.amountOutMin — the router enforces this so the limit price the maker signs in order is exactly what beforeSwap stores via hookData. The hook auto-assigns a salt on create and emits it in AsyncOrderCreated. Submitters can pass order.salt = bytes32(0) on initial submission; the field is only read on cancel / updatePrice / fill paths (where the maker supplies the salt fetched from the indexer or event log). Native input (currency0 = address(0) and zeroForOne = true, OR currency1 = address(0) and zeroForOne = false) requires msg.value == order.amountIn — the router holds the ETH and settles it to PM during unlock. For ERC20 input the maker must approve the router for amountIn of the input token.

function swap(AsyncOrder calldata order, bytes memory userData) external payable;

fillOrder

Filler completes an open order, paying the maker's net minimum plus the protocol fee. For ERC20 output, approve the router for that gross amount. For native output, msg.value must equal the live net price plus the protocol fee; a stale or excessive deposit reverts rather than stranding the difference. Native output is currency1 for zeroForOne, otherwise currency0. maxPrice caps total output paid, including the fee — it protects fillers from a maker who front-runs them with updatePrice to bump the order's stored price. Pass type(uint256).max to disable the check.

function fillOrder(AsyncOrder calldata order, uint256 maxPrice, bytes calldata) external payable;

swapWithSig

Relayer submits a maker's signed order. The maker signs a Permit2 PermitWitnessTransferFrom for amountIn of the input token with spender = Router and the AsyncOrder witness (see OrderSignatures), so one signature both approves the transfer and commits to the order. Input then lands in the hook escrow exactly as in swap. Requires a prior Permit2 approval of the input token; native input is not supported (use swap).

function swapWithSig(AsyncOrder calldata order, PermitData calldata permit, ExecutorGrant calldata grant) external;

cancelWithSig

Relayer submits a maker's signed EIP-712 CancelOrder. Input returns to the maker.
